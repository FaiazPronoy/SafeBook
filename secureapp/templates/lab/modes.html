ECB does not hide a picture

The same {{ blocks }} blocks of greyscale, encrypted three ways with the same AES key. ECB maps every identical block to the same ciphertext, so the flat areas of the picture stay flat and the shape survives. Reload for fresh keys.

The picture has large flat areas, so the plaintext itself repeats blocks. ECB keeps that count almost exactly — that is the leak. CBC and GCM chain or counter each block, so two identical inputs land on different outputs and the count drops to nothing.
