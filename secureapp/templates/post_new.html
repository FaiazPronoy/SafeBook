What happens when you save

  1. A fresh 256 bit key is drawn for this post alone.
  2. Title and body are encrypted with AES-256-GCM under that key.
  3. An HMAC-SHA256 is taken over the whole row, tying the fields together.
  4. The post key is wrapped with your data key, which only your password opens.
  5. If you tick publish, it is wrapped a second time with the server key — and only then can the feed read it.
Publishing later adds that second wrapping. The post itself is never re-encrypted.
